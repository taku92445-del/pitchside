# Pitchside チーム管理

サッカー部・クラブチームのための、チーム管理とキャリア支援のアプリ（試作版）です。
1つのHTMLファイル（`index.html`）だけで動きます。

## できること

**毎日**
- 今日の記録：体調・睡眠・食事（主食・主菜・副菜・乳製品・果物）・体重を30秒で記録
- 予定と事前の出欠回答：練習・試合・遠征の予定に「参加・不参加・未定」を回答
- 出欠・遅刻：月の遅刻回数と面談ラインのお知らせ
- 連絡：クラブ全体・チーム・選手だけ・スタッフだけの部屋、重要連絡の既読確認

**チーム**
- 選手名簿（連絡先・緊急連絡先・アレルギーなど）
- 戦術ボード（マーカー・ボール・矢印）
- 試合記録（時間つきメモ、出場メンバー・出場時間・得点・アシスト）
- 日報、部のルール・規律（確認状況つき）

**からだ**
- コンディション・怪我（復帰予定日、脳しんとうの段階的復帰ステップ）
- 睡眠・食事・体重、栄養・筋トレ（年代別の目安、食品の成分）
- 女子選手の月経の記録（本人だけ）
- キャリア・進路のロードマップ

**安全・設定**
- 暑さ指数（WBGT）を入れると運動・試合の目安を表示
- メンバーの一括登録（Excel・スプレッドシートから貼り付け）、招待リンク・QR・参加番号
- 参加時の同意（18歳未満は保護者の同意も）
- プライバシー設定、データのバックアップ

## 使い方

公開ページ：https://taku92445-del.github.io/pitchside/

- **代表者**：「新しくクラブを作る」からクラブを作成（見本データ入りで試すこともできます）
- **選手・スタッフ**：招待リンク（QRコード）を開き、自分の名前を選んで、参加番号（4けた）を入れて参加
- データはFirebase（Authentication・Cloud Firestore、東京リージョン）に保存され、同じクラブのメンバーで共有されます
- Firebaseが読み込めない場所（Claudeのアーティファクトなど）では、これまで通り端末の中だけで動く見本版になります

## 仕組み

- ログイン：メールアドレスとパスワード
- 参加：招待コード → 名前 → 参加番号（本人／保護者を選択）。参加番号の照合と「同じ名前に2人が参加できない」ことは、`firestore.rules` でサーバー側でも確かめます
- 個人の記録は、読める人ごとに分けて保存します（`clubs/{クラブ}/pd`）
  - `_s`：本人とスタッフ（体調・出欠に関わる情報、アレルギー、日報）
  - `_m`：本人と、クラブ代表が許可したスタッフ（血液型・持病・常用薬・病院）
  - `_p`：本人だけ（プライバシー設定で「自分だけ」にした項目）
  - `_d`：本人とスタッフの個別連絡
- スタッフ専用メモ・スタッフの部屋は `staffonly`（スタッフだけ）
- 参加番号はスタッフだけが読める場所に保存し、選手には見えません
- 女子選手の月経の記録は端末の中だけに保存し、クラウドには送りません
- 卒業・退部にするとアプリに入れなくなり、「完全に削除」で記録をすべて消せます

## アプリとして使う（ホーム画面に追加）

- Android：ブラウザのメニュー →「ホーム画面に追加」／「アプリをインストール」
- iPhone：Safariの共有ボタン →「ホーム画面に追加」

## スマホへの通知を有効にする（任意）

通知を送るにはサーバー側の処理（`functions/`）が必要で、Firebaseの **Blazeプラン（従量課金・無料枠あり）** が必要です。

1. Firebaseコンソール → プロジェクトの設定 → Cloud Messaging → ウェブプッシュ証明書で「鍵ペアを生成」し、その文字列を `index.html` の `FB_VAPID` に入れる
2. Firebaseを Blazeプランにする（予算アラートの設定をおすすめします）
3. Google Cloud でサービスアカウントの鍵（JSON）を作り、GitHubの Settings → Secrets → Actions に `FIREBASE_SERVICE_ACCOUNT` として登録
4. GitHubの Settings → Variables → Actions に `ENABLE_FUNCTIONS` = `true` を登録

鍵を登録すると、`firestore.rules` の変更も自動でFirebaseに反映されるようになります（3だけでも可）。

## 今の制限

- 200人規模で毎日使うと、Firebaseの無料枠（読み取り回数）を超える可能性があります
- 試合・出欠・予定などチームで共有する情報は、同じクラブのメンバー全員が読めます
