# Pitchside チーム管理

サッカー部・クラブチームのための、チーム管理とキャリア支援のアプリ（試作版）です。
1つのHTMLファイル（`index.html`）だけで動きます。

## できること

**毎日**
- 今日の記録：体調・睡眠・食事（主食・主菜・副菜・乳製品・果物）・体重を30秒で記録
- 予定と事前の出欠回答：練習・試合・遠征の予定に「参加・不参加・未定」を回答
- 出欠・遅刻：月の遅刻回数と面談ラインのお知らせ
- 連絡：クラブ全体・チーム・選手だけ・スタッフだけの部屋、重要連絡の既読確認

**チーム**
- 選手名簿（連絡先・緊急連絡先・アレルギーなど）
- 戦術ボード（マーカー・ボール・矢印）
- 試合記録（時間つきメモ、出場メンバー・出場時間・得点・アシスト）
- 日報、部のルール・規律（確認状況つき）

**からだ**
- コンディション・怪我（復帰予定日、脳しんとうの段階的復帰ステップ）
- 睡眠・食事・体重、栄養・筋トレ（年代別の目安、食品の成分）
- 女子選手の月経の記録（本人だけ）
- キャリア・進路のロードマップ

**安全・設定**
- 暑さ指数（WBGT）を入れると運動・試合の目安を表示
- メンバーの一括登録（Excel・スプレッドシートから貼り付け）、招待リンク・QR・参加番号
- 参加時の同意（18歳未満は保護者の同意も）
- プライバシー設定、データのバックアップ

## 今の制限

- データは各端末のブラウザの中だけに保存されます（サーバーなし）。
- 招待リンクは見本です。複数の端末で同じデータを使うには、Firebaseなどのサーバーへの接続が必要です。

## 今後の予定

1. Firebase（ログイン・データベース）につないで、部員全員で使えるようにする
2. 通知（予定・重要連絡）
3. 保護者向けの連絡

## 注意

このリポジトリには、プログラムと見本のデータだけを入れてください。実際の部員の名前・連絡先・体の記録は入れないでください。
